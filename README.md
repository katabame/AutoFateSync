自動レベルシンクプラグイン

## プラグイン概要
FATEの範囲に入った際にレベルシンクが必要な場合、自動的にレベルシンクを行います。

* `/afs`で設定ウィンドウを開きます
* `/afs on`で自動レベルシンクを有効にします
* `/afs off`で自動レベルシンクを無効にします
